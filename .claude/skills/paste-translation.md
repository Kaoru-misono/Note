# 写入翻译内容

用户粘贴原文翻译文本后，格式化并写入对应的 `-translation.md` 文件。

## 步骤

1. **确定目标文件**：根据上下文确定写入哪个翻译文件。如果文件已存在且有内容，追加到末尾；如果是骨架文件，替换占位内容。

2. **格式化公式**：
   - 独立成行的公式用 `$$...$$`，不用单 `$`
   - 编号公式加 `\tag{编号}`，如 `\tag{2.7}`
   - 编号公式下一行加 Obsidian 块锚点 `^eq-{章}-{编号}`，如 `^eq-2-7`
   - 内联公式用 `$...$`
   - `aligned` 环境中不要嵌套 `$`，注释用 `\text{}` 包裹

3. **格式化图片**：
   - 图片用 HTML `<div>` 居中，`<img>` 标签指向 `assets/` 目录
   - 图注释放在 `</div>` 后面，用 markdown 斜体 `*...*`
   - 图注释中可包含 `$LaTeX$` 公式（因为在 HTML 外面）
   - 每张图加 `^fig-{章}-{编号}` 锚点，如 `^fig-2-3`
   - 并排图片用 flexbox 布局，`<figcaption>` 内容也移到 `</div>` 外

4. **格式化代码**：
   - C++ 代码用 ` ```cpp ` 代码块
   - 4 空格缩进，长参数列表换行对齐
   - 代码不翻译，前后说明文字翻译

5. **构建公式引用**：
   - 同文件内引用：`[[#^eq-2-7|公式 (2.7)]]`
   - 跨文件引用：`[[C2.1-xxx-translation#^eq-2-7|公式 (2.7)]]`

6. **更新 status**：如果本节翻译全部完成，将 frontmatter 的 `status` 改为 `done`

## 注意事项

- 忠实原文结构，不重组内容（重组是笔记文件的事）
- 术语中文为主，BSDF/PDF 等缩写保留英文
- 代码块内的对齐要整齐，不用过长的行
