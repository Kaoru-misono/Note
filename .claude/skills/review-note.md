# 审查并写入笔记

用户从外部（如 claude.ai）发来笔记内容后，审查、修复格式问题，写入对应的笔记文件。

## 审查清单

### 1. 公式格式
- [ ] 所有独立成行的公式使用 `$$...$$`，不用单 `$`
- [ ] `aligned` 环境中注释不嵌套 `$`，用 `\text{}` 或移到环境外
- [ ] `\boxed{}` 等特殊命令在 Obsidian 中能正常渲染

### 2. Wikilink 前缀
- [ ] 所有 `[[filename]]` 使用 `C{章}.{节}-` 前缀
- [ ] 翻译文件链接：`[[C2.1-xxx-translation]]`
- [ ] 其他章节链接：`[[C2.2-xxx]]`
- [ ] 尚未创建的概念笔记保留为预留 wikilink（不需要前缀）

### 3. 公式引用链接
- [ ] 笔记中提到编号公式时，构建到翻译文件的跳转链接
- [ ] 格式：`[[C2.4-xxx-translation#^eq-2-21|公式 2.21]]`
- [ ] 未来章节的公式保持纯文本

### 4. 图片内嵌
- [ ] 笔记中讨论图片时，直接内嵌图片（不只放跳转链接）
- [ ] 使用 HTML `<div>` 居中 + markdown 图注释格式
- [ ] 图注释包含到翻译文件中对应图的跳转链接
- [ ] 格式：`*[[C2.3-xxx-translation#^fig-2-3|图 2.3]]：说明文字*`

### 5. 代码块
- [ ] 4 空格缩进，长参数换行对齐
- [ ] 与翻译文件中的代码格式保持一致

## 写入步骤

1. 按审查清单修复所有问题
2. 写入目标笔记文件
3. 更新 `index/catalog.md`（如果是新文件）
4. 报告修复了哪些问题

## 注意事项

- 不修改笔记的内容和结构（那是用户的决定）
- 只修复格式、链接、公式渲染相关的问题
- 如果发现内容层面的问题（如概念错误），报告给用户但不擅自修改
