# Study Notes 笔记规范

本文件补充根目录 CLAUDE.md 的规则，专门针对 study-notes 类型笔记的写作风格和结构。

## 笔记体系

每个章节小节产出两个文件，分开存放：

| 文件 | 位置 | 用途 |
|------|------|------|
| `C2.1-xxx.md` | `chapter2/` | **学习笔记** — 重组、提炼、加批注 |
| `C2.1-xxx-translation.md` | `chapter2/translations/` | **原文翻译** — 忠实翻译，保留原文结构 |

目录结构示例：

```
chapter2/
├── C2.1-monte-carlo-basics.md        # 笔记
├── C2.2-improving-efficiency.md
├── C2-glossary.md                    # 章级术语表
├── assets/                           # 图片
└── translations/                     # 翻译
    ├── C2.1-monte-carlo-basics-translation.md
    └── C2.2-improving-efficiency-translation.md
```

笔记文件开头通过 `> 原文翻译：[[C2.1-xxx-translation]]` 链接到翻译（Obsidian wikilink 按文件名匹配，不含路径）。

## 笔记文件的写作风格

### 结构

1. **标题** = 原书章节编号 + 英文标题（如 `# 2.1 Monte Carlo: Basics`）
2. **开头** = 原文翻译链接 + 前置知识链接 + 一段话概括本节做什么
3. **正文** = 按原书子节组织，但可以重组内容、合并或拆分
4. **末尾** = 核心概念关联（wikilink 列表）+ 要点总结（表格）

### 内容原则

- **重组而非复述**：笔记不是翻译的缩写版，而是用更清晰的结构重新组织知识
- **加入理解性批注**：用 `> [!tip]`、`> [!important]`、`> [!warning]` 等 callout 加入个人理解、直觉解释、易错点
- **证明要带注释**：推导步骤旁标注每步用了什么性质（如 `（性质一+二）`、`（期望值定义）`）
- **代码与公式对应**：pbrt 代码片段后用表格逐项对应公式各部分
- **具体数字示例**：抽象公式后补充具体数值代入验证（如 `a=1, b=3` 的 CDF 例子）
- **指出数值陷阱**：浮点精度问题、除零保护、边界情况

### 公式规范

- 独立成行的公式用 `$$...$$`，不用单 `$`
- 内联公式用 `$...$`
- 编号公式在翻译文件中用 `\tag{2.7}` + `^eq-2-7` 锚点
- 笔记文件中引用公式时可以是纯文本（如"公式 2.7"），无需每处都加跳转链接

### 图片规范

- 笔记中讨论到图片时，**直接内嵌图片**方便阅读，不要只放链接
- 图注释用 markdown 斜体，包含到翻译文件中对应图的跳转链接
- 格式：

```markdown
<div style="text-align: center;">
<img src="assets/xxx.svg" style="max-width: 400px;">
</div>

*[[C2.3-xxx-translation#^fig-2-3|图 2.3]]：说明文字，可包含 $LaTeX$*
```

### Callout 使用约定

| 类型 | 用途 | 示例场景 |
|------|------|---------|
| `[!important]` | 核心公式、关键性质、全书级别的重要结论 | "公式 2.7 是全书最核心的公式" |
| `[!tip]` | 直觉理解、图的阅读方式、巧妙设计 | "图 2.5 的阅读方式"、"uRemapped 的巧妙之处" |
| `[!warning]` | 易错点、数值陷阱、选错会帮倒忙的情况 | "重要性采样选错分布会帮倒忙" |
| `[!note]` | 补充说明、原文未涉及但相关的概念 | "偏差与一致性" |
| `[!example]` | 具体数值代入验证 | "以 a=1, b=3 为例" |
| `[!abstract]` | 总览性表格、技术对比 | "四大技术各解决一个不同的问题" |

### 要点总结表格

每篇笔记末尾用表格总结核心要点，格式：

```markdown
| 概念 | 要点 |
|------|------|
| MC 估计器 | $F_N = \frac{1}{N}\sum \frac{f(X_i)}{p(X_i)}$，无偏 |
| 收敛速率 | $O(1/\sqrt{N})$，与维度无关 |
```

## 翻译文件的写作风格

- **忠实原文**：保留原书的段落结构和论述顺序
- **中文为主，术语保留英文**：如"蒙特卡洛估计器"而非"Monte Carlo estimator"，但 BSDF、PDF 等缩写保留
- **公式用 LaTeX**：所有公式转为 LaTeX，编号公式加 `\tag` 和 `^eq-` 锚点
- **代码原样保留**：`cpp` 代码块不翻译，但前后的说明文字翻译
- **图片内嵌**：图片用 HTML 居中，图注释放 `<div>` 外以支持 LaTeX 渲染，加 `^fig-` 锚点

## 章级辅助文件

- `C2-glossary.md` — 术语表，收录不常见的专业词汇（常见概念不重复收录）
- `assets/` — 图片目录，从原书网站下载的 SVG/PNG

**每次写完笔记后必须更新术语表**：检查新笔记中出现的专业术语，将尚未收录的添加到对应章节的 glossary 文件中。

## pbrt 代码相关

- 代码片段保留原始 C++ 格式
- 注释可以翻译为中文
- 笔记中提到 pbrt 的设计模式时（如"采样三件套"），用表格总结函数签名和用途
- 类名、函数名用 `` `backtick` `` 标记
