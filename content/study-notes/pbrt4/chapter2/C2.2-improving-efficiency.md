# 2.2 Improving Efficiency

> 原文翻译：[[C2.2-improving-efficiency-translation]]
> 前置知识：[[C2.1-monte-carlo-basics]]（§2.1 的基本估计器和方差概念）

给定无偏 MC 估计器，采样数与方差有可靠的关系——增加样本就能可预测地降低误差。但计算时间有限，所以需要让每个样本发挥更大作用。本节介绍 pbrt 中最重要的四种技术。

> [!abstract] 四大技术各解决一个不同的问题
> | 技术 | 解决的问题 | 对方差的影响 |
> |------|-----------|-------------|
> | ① 分层采样 | 样本聚集、覆盖不均 | 降低（永远不会更差） |
> | ② 重要性采样 | 样本浪费在低值区域 | 降低（选错 PDF 会更差） |
> | ③ MIS | 单一策略无法匹配乘积 | 降低（消除方差尖峰） |
> | ④ 俄罗斯轮盘赌 | 浪费时间在低贡献路径上 | 增加方差，但提高效率 |

---

## 2.2.1 Stratified Sampling（分层采样）

### 核心思想

将积分域 $\Lambda$ 细分为 $n$ 个不重叠的区域（层）$\Lambda_1, \Lambda_2, \ldots, \Lambda_n$，在每个层内独立采样。保证每个区域都有样本覆盖，避免纯随机采样的聚集问题。

简单例子：像素超采样时将像素区域分成 $k \times k$ 网格，每格内取一个随机样本。

### 方差分析

设第 $i$ 层的体积分数为 $v_i$，层内均值为 $\mu_i$，层内方差为 $\sigma_i^2$，全局均值为 $Q$。

**分层后的方差：**
$$V[F_n]_{\text{分层}} = \frac{1}{n} \sum_i v_i \sigma_i^2$$

**不分层的方差（公式 2.12）：**
$$V[F]_{\text{无分层}} = \frac{1}{n} \left[ \sum_i v_i \sigma_i^2 + \underbrace{\sum_i v_i (\mu_i - Q)^2}_{\ge 0,\text{ 组间方差}} \right]$$

> [!important] 分层采样永远不会增加方差
> 无分层的方差比分层多了一个**组间方差**项 $\sum v_i(\mu_i - Q)^2$，该项必然 $\ge 0$。只有当 $f$ 在每个层的均值都相同时（即组间方差为零），分层才不产生改善。
>
> 推论：为了最大化方差缩减，应让各层均值尽可能不同 → 紧凑的层更好（层越大，内部变化越多，$\mu_i$ 越接近 $Q$）。

### 维度灾难与应对

- $D$ 维空间中每维 $S$ 个层需要 $S^D$ 个样本 → 高维不可行
- **应对：** 对部分维度独立分层，随机组合不同维度的样本（§8.5）
- 应优先分层对被积函数值影响最大的维度

### 与后续章节的关系

第 8 章的 `StratifiedSampler`、`HaltonSampler`、`SobolSampler` 都是分层思想的不同实现。低差异序列（Halton、Sobol）可以看作"更聪明的分层"——用数论方法生成覆盖性更好的样本。

## 2.2.2 Importance Sampling（重要性采样）

### 核心思想

MC 估计器 $F_n = \frac{1}{n}\sum \frac{f(X_i)}{p(X_i)}$ 在 $p(x)$ 与 $f(x)$ 形状相似时收敛更快。直觉：让样本集中在被积函数值大的地方，不浪费在值小的地方。

### 完美情况：方差为零

若 $p(x) = cf(x)$，归一化要求 $c = 1/\int f(x)\,dx$，此时：

$$\frac{f(X_i)}{p(X_i)} = \frac{1}{c} = \int f(x)\,dx \quad \text{（常数！方差 = 0）}$$

当然这要求已知积分值——正是我们要算的东西。但它指明方向：**让 $p$ 尽量接近 $f$ 的形状，$f/p$ 就越平坦，方差就越小。**

### 现实例子：窄高斯函数

$f(x) = e^{-1000(x-1/2)^2}$ 在 $[0,1]$ 上大部分区域接近零：

| 采样策略 | 方差 | 相对均匀采样 |
|---------|------|------------|
| 均匀采样 $p=1$ | 0.0365 | 1× |
| 好的分段常数 PDF（集中在峰值处）| ~0.0054 | **6.7× 改善** |
| 糟糕的 PDF（避开峰值处）| ~0.197 | **5.4× 恶化** |

> [!warning] 重要性采样选错分布会帮倒忙
> 糟糕的 PDF 不仅在被积函数大的地方生成更少样本，而且偶尔在那里取到样本时 $f/p$ 会爆炸——方差反而比均匀采样更高。在渲染中评估被积函数涉及追踪光线的开销，用劣质分布再靠增加样本弥补是不可取的。

### 在 pbrt 中的实现模式

每个 `BxDF` 子类都实现 `Sample_f()` 方法，按自身散射分布（而非均匀）生成采样方向：

```cpp
// BxDF 的重要性采样接口
BSDFSample bsdf.Sample_f(wo, u, mode);
// 返回:
//   .f    = BSDF 值 f_r(ω_i, ω_o)
//   .wi   = 采样方向（按 BSDF 形状分布）
//   .pdf  = 该方向的概率密度 p(ω_i)
```

- `ConductorBxDF`: 按 GGX 微表面分布采样
- `DielectricBxDF`: 按 Fresnel 系数分配反射/折射概率
- 理想镜面: 直接返回精确的反射/折射方向

## 2.2.3 Multiple Importance Sampling（MIS）

### 问题：被积函数是乘积

渲染中的积分通常是多个因子的乘积：$\int f_a(x) \cdot f_b(x) \, dx$（如 BSDF × 入射辐射 × $\cos\theta$）。

即使我们有分别匹配 $f_a$ 和 $f_b$ 的完美采样分布 $p_a$ 和 $p_b$：
- 用 $p_a$ 采样 → 估计器方差 $\propto V[f_b]$（$f_a$ 被约掉了，$f_b$ 的方差留下）
- 用 $p_b$ 采样 → 估计器方差 $\propto V[f_a]$
- **简单平均两个估计器也不行** → 因为方差是可加的，高方差一旦潜入就无法通过加低方差估计器消除

### MIS 的解法

从多个分布中采样，用**权重函数**组合，使得每个策略在其擅长的区域获得高权重、在弱区获得低权重。

两个分布 $p_a$、$p_b$ 各取一个样本 $X \sim p_a$、$Y \sim p_b$（公式 2.13）：

$$F = w_a(X)\frac{f(X)}{p_a(X)} + w_b(Y)\frac{f(Y)}{p_b(Y)}$$

**无偏条件：** 当 $f(x) \neq 0$ 时 $\sum_i w_i(x) = 1$；当 $p_i(x) = 0$ 时 $w_i(x) = 0$。

### Balance Heuristic（公式 2.14）

$$w_i(x) = \frac{n_i \cdot p_i(x)}{\sum_j n_j \cdot p_j(x)}$$

两策略各一样本时展开为：

$$F = \frac{f(X)}{p_a(X) + p_b(X)} + \frac{f(Y)}{p_a(Y) + p_b(Y)}$$

> [!tip] 直觉理解
> 每次 $f$ 的求值除以的是**所有策略在该点的 PDF 之和**。如果 $p_a$ 在某点概率很低但 $p_b$ 概率很高，除以 $p_a + p_b$ 就自动降低了该样本的贡献——系统认识到 $p_b$ 在这个点更有效。

### Power Heuristic（公式 2.15，实践中更常用）

$$w_i(x) = \frac{(n_i \cdot p_i(x))^\beta}{\sum_j (n_j \cdot p_j(x))^\beta}$$

比 balance heuristic 进一步压制低概率分布的贡献。pbrt 硬编码 $\beta = 2$。

### pbrt 源码

```cpp
// src/pbrt/util/sampling.h

Float BalanceHeuristic(int nf, Float fPdf, int ng, Float gPdf) {
    return (nf * fPdf) / (nf * fPdf + ng * gPdf);
}

Float PowerHeuristic(int nf, Float fPdf, int ng, Float gPdf) {
    Float f = nf * fPdf, g = ng * gPdf;
    if (IsInf(Sqr(f))) return 1;  // 数值保护
    return Sqr(f) / (Sqr(f) + Sqr(g));
}
```

### 单样本模型（公式 2.16）

不需要从所有分布中采样。以概率 $q_i$ 选择策略 $p_i$，抽取样本 $X$：

$$\frac{w_i(X)}{q_i} \cdot \frac{f(X)}{p_i(X)}$$

对单样本模型，balance heuristic **被证明是最优的**。

### MIS 补偿

当使用 MIS 时，不要求所有 PDF 在函数非零处都非零——只需其中一个即可。

**问题：** 所有分布都在低值区域分配了概率 → 低值区被过度采样，高值区采样不足。

**解法：** 锐化部分（不是全部）分布，将低概率区域截断为零：

$$p'(x) = \frac{\max(0,\; p(x) - \delta)}{\int \max(0,\; p(x) - \delta)\, dx}$$

§12.5 中用于环境贴图光源采样。

### MIS 的渲染应用（第 13 章直接光照）

对每个着色点：
1. **光源采样：** 从光源分布采样方向 $\omega_\text{light}$，计算 BSDF 的 $\text{pdf}_\text{bsdf}$，用 `PowerHeuristic` 加权
2. **BSDF 采样：** 从 BSDF 分布采样方向 $\omega_\text{bsdf}$，计算光源的 $\text{pdf}_\text{light}$，用 `PowerHeuristic` 加权
3. **两部分相加**

光滑表面 BSDF 采样赢，粗糙表面光源采样赢，MIS 让两种情况都表现良好。

> [!note] MIS 的一个缺点
> 如果某个策略已经非常匹配被积函数，MIS 可能略微增加方差。但对渲染应用几乎总是值得的。

## 2.2.4 Russian Roulette and Splitting

### 俄罗斯轮盘赌

#### 动机

渲染中估计器常含计算代价不同的因子：$f(X) \cdot v(X) / p(X)$，其中 $f(X)$ 容易计算（表面散射），$v(X)$ 很贵（追踪阴影光线）。如果 $f(X)$ 很小，花大代价算 $v(X)$ 就不划算。但又不能直接跳过——否则估计器持续低估。

#### 方法

选择终止概率 $q$（可基于被积函数的估计值，值越小 $q$ 越大）：

$$\text{结果} = \begin{cases} 0 & \text{以概率 } q \\ \dfrac{f(X) \cdot v(X)}{p(X) \cdot (1-q)} & \text{以概率 } 1-q \end{cases}$$

#### 无偏性证明

$$E[\text{结果}] = q \cdot 0 + (1-q) \cdot \frac{f(X) \cdot v(X)}{p(X) \cdot (1-q)} = \frac{f(X) \cdot v(X)}{p(X)} \quad \checkmark$$

#### 关键性质

> [!important] 增加方差，但提高效率
> 俄罗斯轮盘赌**永远不会降低方差**——它总是增加方差。但它通过跳过低贡献样本节省时间，提高了**效率** $\epsilon = 1/(V \cdot T)$。
>
> 节省的时间可以用来取更多其他样本，总体效果是正面的。

> [!warning] 糟糕的终止概率会毁掉图像
> 对所有相机光线以 $q = 0.99$ 终止 → 只追踪 1% 的光线，每条权重 ×100。数学上"正确"，视觉上灾难：大部分黑色像素中夹杂极亮的萤火虫。

#### 在 pbrt PathIntegrator 中的使用

```cpp
SampledSpectrum Li(...) {
    SampledSpectrum beta(1.f);  // 路径吞吐量
    for (int depth = 0; ; ++depth) {
        // ... 求交、采样光源 ...

        // 俄罗斯轮盘赌（从第1次弹射后开始）
        if (depth > 0) {
            // q = 1 - 最大分量 → 贡献越小越可能终止
            Float q = std::max(0.f, 1.f - beta.MaxComponentValue());
            if (sampler.Get1D() < q) break;  // 终止
            beta /= (1.f - q);               // 补偿
        }
        // ... 采样 BSDF、更新 beta、继续追踪 ...
    }
}
```

### Splitting

与轮盘赌互补：轮盘赌在不重要维度**减少**样本，splitting 在重要维度**增加**样本。

例如直接光照计算：每像素一条相机光线通常够了（像素间变化平滑），但每个着色点可能需要对多个光源各取样本（光照变化剧烈）。Splitting 的思想就是在不同维度分配不同数量的样本，把计算资源集中在方差最高的维度。

## 四大技术如何在 pbrt 中协同工作

> [!abstract] PathIntegrator 的一次路径追踪
> **分层采样器**（第 8 章 Sampler）生成高质量随机数
> → 在每个弹射点用**重要性采样**（`BxDF::Sample_f`）生成散射方向
> → 直接光照用 **MIS** 组合 BSDF 采样和光源采样（`PowerHeuristic`）
> → **俄罗斯轮盘赌**决定路径是否继续（`beta.MaxComponentValue()` 作为存活概率）
>
> 四个技术层层叠加，共同将噪点降到可接受水平。

## 要点总结

| 概念 | 要点 |
|------|------|
| 分层采样 | 切格子、每格一样本；方差减少 = 组间方差；永远不会更差 |
| 重要性采样 | 让 $p \approx f$ 使 $f/p$ 平坦；选错 PDF 会帮倒忙 |
| MIS | 多策略 + 权重组合；power heuristic $\beta=2$；消除方差尖峰 |
| Balance heuristic | $w_i = n_i p_i / \sum n_j p_j$；单样本模型下最优 |
| 俄罗斯轮盘赌 | 概率终止 + 补偿 = 无偏；增加方差但提高效率 |
| Splitting | 在重要维度增加样本；与轮盘赌互补 |
| 协同工作 | Sampler → 重要性采样 → MIS → 轮盘赌，层层叠加 |
