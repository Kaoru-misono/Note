# 2.4 Transforming between Distributions

> 原文翻译：[[C2.4-transforming-distributions-translation]]
> 前置知识：[[C2.3-sampling-inversion-method]]（反演法三步曲）、[[C2.1-monte-carlo-basics]]（条件概率[[C2.1-monte-carlo-basics-translation#^eq-2-1|公式 2.1]]）

§2.3 的反演法将均匀随机变量变换到目标分布。本节研究更一般的问题：**对随机变量做任意变换后，概率密度怎么变？** 这个理论的核心应用是推导多维采样算法。

---

## 一维变换公式

### 推导

设随机变量 $X \sim p(x)$，CDF 为 $P(x)$。对 $X$ 施加一对一函数 $f$，得到 $Y = f(X)$，求 $Y$ 的 PDF。

因为 $f$ 一对一（导数严格正或严格负），CDF 之间满足：

$$P_f(y) = P_f(f(x)) = P(x)$$

两边对 $x$ 求导，利用链式法则：

$$p_f(y) \cdot \frac{df}{dx} = p(x)$$

一般形式（考虑导数可能为负）：

$$\boxed{p_f(y) = \left|\frac{df}{dx}\right|^{-1} \cdot p(x)}$$

> [!tip] 直觉理解
> $|df/dx|$ 衡量的是变换 $f$ 在 $x$ 处的"拉伸率"。如果 $f$ 在某处拉伸了 2 倍，同样多的概率被分摊到 2 倍宽的区间上，密度就变成原来的 $1/2$。

### 示例

$p(x) = 2x$（$[0,1]$ 上），$f(x) = \sin x$，求 $Y = \sin(X)$ 的 PDF：

$$p_f(y) = \frac{p(x)}{|\cos x|} = \frac{2x}{\cos x} = \frac{2\arcsin y}{\sqrt{1-y^2}}$$

### 反过来用：已知目标分布，求变换函数

通常我们有 $X \sim p(x)$，想得到 $Y \sim p_f(y)$。令两个 CDF 相等 $P_f(y) = P(x)$，立即得到：

$$f(x) = P_f^{-1}(P(x))$$

> [!important] 这是反演法的推广
> 如果 $X$ 在 $[0,1)$ 上均匀分布，$P(x) = x$，则 $f(x) = P_f^{-1}(x)$——就是 §2.3 的反演法。所以反演法是本节变换理论的特例。

## 2.4.1 多维变换

### Jacobian 行列式

$d$ 维随机变量 $X \sim p(x)$，双射变换 $Y = T(X)$，密度关系为（[[C2.4-transforming-distributions-translation#^eq-2-21|公式 2.21]]）：

$$\boxed{p_T(y) = \frac{p(x)}{|J_T(x)|}}$$

其中 $|J_T|$ 是变换 $T$ 的 **Jacobian 矩阵**行列式的绝对值：

$$J_T = \begin{pmatrix} \partial T_1/\partial x_1 & \cdots & \partial T_1/\partial x_d \\ \vdots & \ddots & \vdots \\ \partial T_d/\partial x_1 & \cdots & \partial T_d/\partial x_d \end{pmatrix}$$

> [!tip] Jacobian 的直觉
> 一维中 $|df/dx|$ 衡量拉伸率，多维中 $|J_T|$ 衡量的是变换在该点的**面积/体积缩放因子**。概率密度是"每单位面积/体积的概率"，面积变了，密度就要反向补偿。

### 极坐标变换（2D）

$$x = r\cos\theta, \quad y = r\sin\theta$$

Jacobian 矩阵：

$$J_T = \begin{pmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta \end{pmatrix}$$

行列式 $= r(\cos^2\theta + \sin^2\theta) = r$

从极坐标到笛卡尔：$p(x,y) = p(r,\theta) / r$

从笛卡尔到极坐标（通常我们需要的方向，[[C2.4-transforming-distributions-translation#^eq-2-22|公式 2.22]]）：

$$\boxed{p(r, \theta) = r \cdot p(x, y)}$$

> [!example] 为什么会多出一个 $r$？
> 在极坐标中，半径 $r$ 越大，同样的 $d\theta$ 覆盖的弧长越大。所以同一个 $d\theta$ 在大半径处覆盖更多"面积"，密度需要乘以 $r$ 来补偿。
>
> 具体例子：圆盘上均匀分布，$p(x,y) = 1/\pi$。变换到极坐标后 $p(r,\theta) = r/\pi$——$r$ 越大概率越大，因为外围的"环"面积比内圈大。这就是为什么直接用 $r = \xi$ 均匀采样半径会导致样本聚集在圆心附近（错误），正确做法是 $r = \sqrt{\xi}$。

### 球坐标变换（3D）

给定球坐标表示（公式 3.7），Jacobian 行列式为 $|J_T| = r^2\sin\theta$（[[C2.4-transforming-distributions-translation#^eq-2-23|公式 2.23]]）：

$$p(r, \theta, \varphi) = r^2\sin\theta \cdot p(x, y, z)$$

这个变换很重要——它帮助我们将**方向**表示为单位球面上的点 $(x,y,z)$。在单位球面上 $r=1$，所以 $p(\theta, \varphi) = \sin\theta \cdot p(\omega)$，其中 $\sin\theta$ 因子会出现在所有半球/球面采样的推导中。

## 2.4.2 Marginal-Conditional 方法（多维采样）

### 可分离 vs 不可分离

如果联合密度可分离：$p(x,y) = p_x(x) \cdot p_y(y)$，独立采样 $X$ 和 $Y$ 即可。

但许多有用的密度**不可分离**——两个维度之间有耦合。

### 通用方法

**第一步（边缘分布）：** 积分掉一个维度得到边缘密度（[[C2.4-transforming-distributions-translation#^eq-2-24|公式 2.24]]）：

$$p(x) = \int p(x, y)\, dy$$

$p(x)$ 是特定 $x$ 值在所有可能 $y$ 值上的平均密度。从 $p(x)$ 中采样 $X$。

**第二步（条件分布）：** 用条件概率密度采样 $Y$：

$$p(y|x) = \frac{p(x,y)}{\int p(x,y)\, dy} = \frac{p(x,y)}{p(x)}$$

**推广到更高维：** 积分掉除一个维度外的所有维度 → 采样该维度 → 对剩余条件分布（少一维）重复。

> [!important] Marginal-Conditional 是多维采样的通用框架
> 不管是几维的联合分布，都可以逐维分解：先采样边缘分布得到第一个维度，然后在给定该值的条件下采样第二个维度，以此类推。后续所有多维采样（环境贴图、面积光源等）都用这个框架。

## 完整示例：采样双线性函数

### 函数定义

双线性函数在 $[0,1]^2$ 的四角之间插值（[[C2.4-transforming-distributions-translation#^eq-2-25|公式 2.25]]）：

$$f(x,y) = (1-x)(1-y)\,w_0 + x(1-y)\,w_1 + y(1-x)\,w_2 + x\,y\,w_3$$

$w_0$ 在 $(0,0)$，$w_1$ 在 $(1,0)$，$w_2$ 在 $(0,1)$，$w_3$ 在 $(1,1)$。

积分归一化后 PDF 为：

$$p(x,y) = \frac{4\,f(x,y)}{w_0 + w_1 + w_2 + w_3}$$

```cpp
Float BilinearPDF(Point2f p, pstd::span<const Float> w) {
    if (p.x < 0 || p.x > 1 || p.y < 0 || p.y > 1)
        return 0;
    if (w[0] + w[1] + w[2] + w[3] == 0)
        return 1;
    return 4 *
        ((1-p[0])*(1-p[1])*w[0] + p[0]*(1-p[1])*w[1] +
         (1-p[0])*p[1]*w[2] + p[0]*p[1]*w[3]) /
        (w[0] + w[1] + w[2] + w[3]);
}
```

两个维度**不独立**，所以用 marginal-conditional 方法。

### 第一步：$y$ 的边缘分布

选 $y$ 为边缘分布，积分掉 $x$：

$$p(y) = \int_0^1 p(x,y)\,dx = \frac{2\,[(1-y)(w_0+w_1) + y(w_2+w_3)]}{w_0+w_1+w_2+w_3}$$

$$\propto (1-y)(w_0+w_1) + y(w_2+w_3)$$

这是两个常数值之间的**线性插值**——直接复用 §2.3 的 `SampleLinear()`：

```cpp
p.y = SampleLinear(u[1], w[0] + w[1], w[2] + w[3]);
```

> [!tip] 代码解读
> `SampleLinear(u, a, b)` 从 $(1-x)\,a + x\,b$ 的分布中采样。这里 $a = w_0+w_1$（$y=0$ 时的值），$b = w_2+w_3$（$y=1$ 时的值）。`SampleLinear` 内部自动归一化。

### 第二步：$x$ 的条件分布

应用条件概率公式，化简公共因子：

$$p(x|y) = \frac{p(x,y)}{p(y)} \propto (1-x)\,\underbrace{[(1-y)\,w_0 + y\,w_2]}_{\text{Lerp}(y,\, w_0,\, w_2)} + x\,\underbrace{[(1-y)\,w_1 + y\,w_3]}_{\text{Lerp}(y,\, w_1,\, w_3)}$$

又是一个线性插值——再次复用 `SampleLinear()`，但端点值取决于已采样的 $y$：

```cpp
p.x = SampleLinear(u[0],
    Lerp(p.y, w[0], w[2]),
    Lerp(p.y, w[1], w[3]));
```

### 完整采样函数

```cpp
Point2f SampleBilinear(Point2f u, pstd::span<const Float> w) {
    Point2f p;
    // 第一步：从边缘分布采样 y
    p.y = SampleLinear(u[1], w[0] + w[1], w[2] + w[3]);
    // 第二步：从条件分布采样 x（端点值取决于 y）
    p.x = SampleLinear(u[0],
        Lerp(p.y, w[0], w[2]),
        Lerp(p.y, w[1], w[3]));
    return p;
}
```

### 反演函数：两步反演的逆序

采样时先 $y$ 后 $x$（边缘 → 条件），反演时**先反转 $x$ 再反转 $y$**（逆序）：

```cpp
Point2f InvertBilinearSample(Point2f p, pstd::span<const Float> w) {
    return {
        // 先反转 x（条件分布的逆）
        InvertLinearSample(p.x,
            Lerp(p.y, w[0], w[2]),
            Lerp(p.y, w[1], w[3])),
        // 再反转 y（边缘分布的逆）
        InvertLinearSample(p.y, w[0] + w[1], w[2] + w[3])
    };
}
```

> [!tip] 代码模块化的优雅
> 双线性采样 = 两次一维线性采样的组合。`SampleLinear` / `InvertLinearSample` 作为基础构建块被复用。pbrt 的整个采样系统就是这样从简单组件搭建出复杂功能。

更多多维采样算法参见附录 A.5——包括单位球面/半球上的方向采样、单位圆盘采样等。

## 要点总结

| 概念                   | 要点                                                          |
| -------------------- | ----------------------------------------------------------- |
| 一维变换                 | $p_f(y) = \|df/dx\|^{-1} \cdot p(x)$；拉伸越大密度越低               |
| 反演法是特例               | $X$ 均匀时 $P(x)=x$，变换公式退化为 $f(x) = P_f^{-1}(x)$               |
| Jacobian             | 多维中 $\|df/dx\|$ 变成 $\|J_T\|$，衡量面积/体积缩放因子                    |
| 极坐标                  | $p(r,\theta) = r \cdot p(x,y)$；$r$ 补偿外围环面积更大的事实             |
| 球坐标                  | $p(\theta,\varphi) = \sin\theta \cdot p(\omega)$；出现在所有球面采样中 |
| Marginal-Conditional | 积分掉一维得边缘 → 采样 → 条件分布采样剩余维；通用多维框架                            |
| 双线性采样                | 两次 `SampleLinear` 的组合；反演 = 逆序反转                             |
| 模块化设计                | 复杂采样 = 简单采样的组合，pbrt 全系统遵循此模式                                |
