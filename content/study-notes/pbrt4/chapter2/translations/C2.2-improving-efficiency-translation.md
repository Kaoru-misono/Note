# §2.2 提高效率

给定一个无偏蒙特卡洛估计器，我们处于一个幸运的位置——采样数和方差（即误差）之间有可靠的关系。如果渲染出的图像噪点过多，增加采样数就能以可预测的方式降低误差，给足计算量就能生成足够质量的图像。

然而计算需要时间，而时间往往不够——电影的截止日期迫在眉睫，或者实时渲染器六十分之一秒的时间片即将用完。在采样数有限的情况下，降低方差的唯一选择是想办法让每个样本发挥更大的作用。幸运的是，已经发展出多种技术来改进基本的蒙特卡洛估计器，让采样更高效。这里我们讨论 pbrt 中使用的最重要的几种。

## 2.2.1 分层采样

一类经典且有效的方差缩减技术族基于精心放置样本的位置，以更好地捕捉被积函数的特征（更准确地说，是降低遗漏重要特征的概率）。这些技术在 pbrt 中被广泛使用。

分层采样将积分域 $\Lambda$ 细分为 $n$ 个不重叠的区域 $\Lambda_1, \Lambda_2, \ldots, \Lambda_n$。每个区域称为一个**层**（stratum），它们必须完全覆盖原始域：

$$\bigcup_{i=1}^{n} \Lambda_i = \Lambda$$
^eq-2-11

为了从 $\Lambda$ 中采样，我们在每个 $\Lambda_i$ 内按照密度 $p_i$ 抽取 $n_i$ 个样本。一个简单的例子是像素的超采样：分层采样将像素周围的区域分成 $k \times k$ 的网格，在每个网格单元内均匀抽取一个样本。这比直接取 $k^2$ 个随机样本更好，因为样本位置不太可能聚集在一起。

在单个层 $\Lambda_i$ 内，蒙特卡洛估计为：

$$F_i = \frac{1}{n_i} \sum_{j=1}^{n_i} \frac{f(X_{i,j})}{p_i(X_{i,j})}$$

其中 $X_{i,j}$ 是从密度 $p_i$ 抽取的第 $j$ 个样本。整体估计为 $F = \sum_i v_i \cdot F_i$，其中 $v_i$ 是第 $i$ 层的体积分数（$v_i \in (0, 1]$）。

被积函数在第 $i$ 层的真实均值为：

$$\mu_i = \frac{1}{v_i} \int_{\Lambda_i} f(x) \, dx$$

该层的方差为：

$$\sigma_i^2 = \frac{1}{v_i} \int_{\Lambda_i} (f(x) - \mu_i)^2 \, dx$$

如果我们合理假设各层的样本数 $n_i$ 与体积 $v_i$ 成正比（即 $n_i = v_i \cdot n$），则整体估计器的方差为：

$$V[F_n]_{\text{分层}} = \frac{1}{n} \sum_i v_i \cdot \sigma_i^2$$

而不使用分层时的方差为：

$$V[F]_{\text{无分层}} = \frac{1}{n} \left[\sum_i v_i \cdot \sigma_i^2 + \sum_i v_i \cdot (\mu_i - Q)^2\right] \tag{2.12}$$
^eq-2-12

其中 $Q$ 是 $f$ 在整个域 $\Lambda$ 上的均值。

关于[[#^eq-2-12|公式 (2.12)]] 有两件事需要注意：

**第一，** 右边第二个求和项必然是非负的（因为方差总是非负的）。

**第二，** 这证明了**分层采样永远不会增加方差**。除非右边那个求和项恰好为零——只有当 $f$ 在每个层的均值都相同时才会发生——否则分层总是能降低方差。

为了让分层采样效果最好，应该让各层的均值尽可能不同。这解释了为什么在对函数 $f$ 一无所知时，紧凑的层是更好的选择——如果层太大，内部会包含更多变化，各层的 $\mu_i$ 就会更接近全局均值 $Q$，方差缩减效果就差。

## 2.2.2 重要性采样

重要性采样是一种强大的方差缩减技术，它利用了蒙特卡洛估计器

$$F_n = \frac{1}{n} \sum_i \frac{f(X_i)}{p(X_i)}$$

在样本取自与被积函数 $f(x)$ 形状相似的分布 $p(x)$ 时收敛更快的事实。此时，样本更可能在被积函数幅值相对较大的地方被采取。重要性采样是渲染中最常用的方差缩减技术之一，因为它易于应用，且在使用良好的采样分布时非常有效。

**为什么这样的采样分布能降低误差？** 首先考虑使用 $p(x) \propto f(x)$（即 $p(x) = c \cdot f(x)$）的效果。很容易证明 PDF 的归一化要求：

$$c = \frac{1}{\int f(x) \, dx}$$

找到这样的 PDF 需要已知积分的值——而这正是我们试图估计的东西。但如果我们能够从这个分布中采样，估计器求和的每一项的值将是：

$$\frac{f(X_i)}{p(X_i)} = \frac{1}{c} = \int f(x) \, dx$$

**方差为零！** 当然这很荒谬——如果我们能直接积分 $f$ 就不需要蒙特卡洛了。但如果能找到一个与 $f(x)$ 形状相似的密度 $p(x)$，方差就会降低。

**一个更现实的例子：** 考虑高斯函数 $f(x) = e^{-1000(x-1/2)^2}$，在 $[0,1]$ 上绘图。它在大部分定义域上接近零。$X < 0.2$ 或 $X > 0.3$ 的样本对估计积分几乎毫无帮助。使用均匀采样时，方差约为 0.0365。

在渲染的蒙特卡洛积分中，评估被积函数通常涉及追踪光线的开销，因此我们希望尽量减少采样数——使用劣质采样分布然后靠增加样本数来弥补是一个不可取的选择。

## 2.2.3 多重重要性采样 (MIS)

我们经常面对的积分是两个或多个函数的乘积：$\int f_a(x) \cdot f_b(x) \, dx$。通常可以分别为各个因子推导出单独的重要性采样策略，但很难找到一个与它们乘积相似的策略。这种情况在光线传输的积分中尤其常见——例如光线传输方程（公式 1.1）中 BSDF、入射辐射和余弦因子的乘积。

为了理解对这类乘积应用蒙特卡洛的挑战，暂时假设我们幸运地拥有两个采样分布 $p_a$ 和 $p_b$，它们分别与 $f_a$ 和 $f_b$ 的分布精确匹配。（实际中通常不会这样。）使用[[C2.1-monte-carlo-basics-translation#^eq-2-7|公式 (2.7)]] 的蒙特卡洛估计器，我们有两个选择：

我们可以用 $p_a$ 抽取样本，得到估计器：

$$\frac{f(X)}{p_a(X)} = \frac{f_a(X) \cdot f_b(X)}{p_a(X)} = c \cdot f_b(X)$$

其中 $c$ 是 $f_a$ 的积分值的常数（因为 $p_a(x) \propto f_a(x)$）。这个估计器的方差与 $f_b$ 的方差成正比，而 $f_b$ 的方差本身可能很高。反过来，用 $p_b$ 采样会得到方差与 $f_a$ 的方差成正比的估计器，同样可能很高。在更常见的情况下——采样分布只是近似匹配某个因子——情况通常更糟。

不幸的是，一个直觉上显而易见的解法——从每个分布各取一些样本然后平均两个估计器——也好不到哪去。因为方差是可加的，一旦方差潜入了某个估计器，我们无法通过把它加到另一个低方差估计器上来消除它。

**多重重要性采样 (MIS)** 正好解决这个问题，它提供了一种易于实现的方差缩减技术。基本思想是：在估计积分时，我们应该从多个采样分布中抽取样本，希望其中至少有一个能合理地匹配被积函数的形状，即使我们事先不知道是哪一个。然后 MIS 提供一种方法来加权来自各策略的样本，能够消除由于被积函数值与采样密度不匹配导致的巨大方差尖峰。甚至鼓励使用只针对不常见特殊情况的专用采样程序——当这些情况出现时它们能降低方差，而在一般情况下代价很小。

对于两个采样分布 $p_a$ 和 $p_b$，各取一个样本 $X \sim p_a$ 和 $Y \sim p_b$，MIS 蒙特卡洛估计器为：

$$w_a(X) \cdot \frac{f(X)}{p_a(X)} + w_b(Y) \cdot \frac{f(Y)}{p_b(Y)} \tag{2.13}$$
^eq-2-13

其中 $w_a$ 和 $w_b$ 是权重函数，选择它们使得该估计器的期望值等于 $f(x)$ 的积分。

更一般地，给定 $n$ 个采样分布 $p_i$，从第 $i$ 个分布中取 $n_i$ 个样本 $X_{i,j}$，MIS 蒙特卡洛估计器为：

$$F_n = \sum_{i=1}^{n} \frac{1}{n_i} \sum_{j=1}^{n_i} w_i(X_{i,j}) \cdot \frac{f(X_{i,j})}{p_i(X_{i,j})}$$

权重函数需满足的无偏条件是：当 $f(x) \neq 0$ 时它们之和为 1（即 $\sum_i w_i(x) = 1$），且当 $p_i(x) = 0$ 时 $w_i(x) = 0$。设 $w_i(X) = 1/n$ 对应于简单求和各估计器的情况——我们已经看到这是降低方差的无效方式。更好的做法是让权重函数在对应的采样策略与被积函数匹配良好时相对较大，在不匹配时相对较小，从而降低高方差样本的贡献。

### Balance Heuristic

实践中，一个好的权重函数选择是 **balance heuristic**，它考虑了一个样本可能被生成的所有不同方式，而不仅仅是实际用来生成它的那种。第 $i$ 个采样策略的 balance heuristic 权重函数为：

$$w_i(x) = \frac{n_i \cdot p_i(x)}{\sum_j n_j \cdot p_j(x)} \tag{2.14}$$
^eq-2-14

以两个策略各取一个样本为例，balance heuristic 下[[#^eq-2-13|公式 (2.13)]] 的估计器变为：

$$\frac{f(X)}{p_a(X) + p_b(X)} + \frac{f(Y)}{p_a(Y) + p_b(Y)}$$

每次 $f$ 的求值都除以对应样本的所有 PDF 之和，而不仅仅是生成该样本的那个 PDF。因此，如果 $p_a$ 在某个点以低概率生成了一个样本，而 $p_b$ 在该点有更高概率，那么除以 $p_a(X) + p_b(X)$ 就会降低该样本的贡献。实际上，这些样本在从 $p_a$ 采样时被降权了，因为系统认识到与 $p_b$ 关联的采样策略在积分域的这个点上更有效。

只要至少有一个采样策略在函数值大的地方有合理的采样概率，MIS 权重就能带来显著的方差缩减。

pbrt 中 `BalanceHeuristic()` 实现了[[#^eq-2-14|公式 (2.14)]] 的两分布特例：

```cpp
Float BalanceHeuristic(int nf, Float fPdf, int ng, Float gPdf) {
    return (nf * fPdf) / (nf * fPdf + ng * gPdf);
}
```

### Power Heuristic

实践中，**power heuristic** 往往能进一步降低方差。对于指数 $\beta$，power heuristic 为：

$$w_i(x) = \frac{(n_i \cdot p_i(x))^\beta}{\sum_j (n_j \cdot p_j(x))^\beta} \tag{2.15}$$
^eq-2-15

注意 power heuristic 和 balance heuristic 形式相似，但它进一步降低了相对低概率分布的贡献。pbrt 的实现将 $\beta = 2$ 硬编码；这个参数值在实践中通常效果很好。

```cpp
Float PowerHeuristic(int nf, Float fPdf, int ng, Float gPdf) {
    Float f = nf * fPdf, g = ng * gPdf;
    if (IsInf(Sqr(f))) return 1;
    return Sqr(f) / (Sqr(f) + Sqr(g));
}
```

### 单样本模型

MIS 甚至可以在不从所有分布中采样的情况下应用，这种方法称为**单样本模型**。给定被积函数 $f(x)$，如果以概率 $q_i$ 选择一个采样策略 $p_i$，并从 $p_i$ 中抽取样本 $X$，则单样本估计器：

$$\frac{w_i(X)}{q_i} \cdot \frac{f(X)}{p_i(X)} \tag{2.16}$$
^eq-2-16

给出积分的无偏估计。对于单样本模型，balance heuristic 被证明是最优的。

### MIS 补偿

当使用 MIS 时，并不要求所有 PDF 在函数非零处都非零——只需要其中一个即可。这一观察催生了一种叫做 **MIS 补偿**的技术，它能进一步降低方差。

动机是：如果所有采样分布都在被积函数值小的区域分配了一些概率，那么该区域往往会被过度采样，导致被积函数值大的区域采样不足。MIS 补偿基于锐化一个或多个（但不是全部）概率分布的想法——例如，将它们调整为在之前概率较低的区域概率为零。新的采样分布 $p'$ 可以这样定义：

$$p'(x) = \frac{\max(0, \, p(x) - \delta)}{\int \max(0, \, p(x) - \delta) \, dx}$$

对于某个固定值 $\delta$。这个技术特别容易应用于表格化的采样分布。在 §12.5 中，它被有效地用于环境贴图光源的采样。

### MIS 的一个缺点

如果其中一个采样策略已经非常匹配被积函数，MIS 可能会略微增加方差。但对于渲染应用，MIS 几乎总是值得的——因为它在其他情况下可能出现高方差的场景中提供的方差缩减效果很显著。

## 2.2.4 俄罗斯轮盘赌

俄罗斯轮盘赌是一种通过跳过对最终结果贡献很小的样本评估来提高效率的技术。在渲染中，我们经常有如下形式的估计器：

$$\frac{f(X) \cdot v(X)}{p(X)}$$

其中被积函数由一些容易计算的因子 $f(X)$（如与表面散射光线方式相关的因子）和其他计算代价更高的因子组成，比如需要追踪光线的二值可见性因子 $v(X)$。在这些情况下，评估估计器的计算开销主要在 $v$ 上。

如果 $f(X)$ 为零，显然值得跳过评估 $v(X)$ 的工作，因为它的值不会影响估计器。但 $f(X)$ 很小而不一定为零时怎么办？这些样本不能直接忽略，否则估计器就会持续低估正确结果。

要应用俄罗斯轮盘赌，我们选择一个终止概率 $q$。这个值的选择方式几乎可以是任意的——例如，它可以基于对特定所选样本的被积函数值的估计，当被积函数值越小时终止概率越大。然后：

- 以概率 $q$：结果 $= 0$
- 以概率 $1 - q$：结果 $= \dfrac{f(X) \cdot v(X)}{p(X) \cdot (1 - q)}$

结果估计器的期望值与原始估计器的期望值相同：

$$E[\text{结果}] = q \cdot 0 + (1 - q) \cdot \frac{f(X) \cdot v(X)}{p(X) \cdot (1 - q)} = \frac{f(X) \cdot v(X)}{p(X)}$$

**俄罗斯轮盘赌永远不会降低方差。** 事实上，除非某种方式使方差为零，它总会增加方差。但如果概率选择得当——使得很可能对最终结果贡献小的样本被跳过——它确实能提高效率（效率 $= 1/(\text{方差} \times \text{时间})$）。

**一个陷阱：** 糟糕的俄罗斯轮盘赌权重会大幅增加方差。想象对所有相机光线以 $q = 0.99$ 的终止概率应用轮盘赌——我们只会追踪 1% 的光线，每条权重放大 100 倍。结果图像在严格数学意义上仍然"正确"，但视觉上会很糟糕：大部分黑色像素中夹杂着少数极亮的像素。

### Splitting

俄罗斯轮盘赌减少了在不重要样本上的开销，而 **splitting** 则增加样本数量以提高效率。

考虑计算仅由直接光照引起的反射的问题。忽略像素滤波，这个问题可以写成对像素面积和可见点处方向球面的二重积分。自然的估计方法是生成样本对——一个图像位置和一个朝向光源的方向——然后应用蒙特卡洛估计器。

如果场景中有很多光源或存在投射柔和阴影的面积光，可能需要几十甚至上百个样本才能生成方差可接受的图像。但对于每个像素取多条光线通常是不值得的——大部分情况下一条就够了。

**Splitting 的思想是在不同维度上分配不同数量的样本：** 例如每像素一条相机光线，但在每个着色点对多个光源分别采样。这样把计算资源集中在方差最高的维度上。
