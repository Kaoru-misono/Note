# §2.3 用反演法采样

要计算[[C2.1-monte-carlo-basics-translation#^eq-2-7|公式 (2.7)]] 的蒙特卡洛估计器，必须能够从选定的概率分布中抽取随机样本。有多种技术可以做到这一点，但对渲染最重要的一种是**反演法**（inversion method），它通过反转分布的 CDF，将 $[0,1)$ 上的均匀样本映射到给定的一维概率分布。（在 §2.4.2 中我们将看到如何通过考虑一系列一维分布来将此方法应用于高维函数。）

当与高质量样本（如第 8 章中定义的采样器生成的样本）配合使用时，反演法特别有效。在本书后续部分中，我们将看到反演法被应用于从 BSDF、光源、相机和散射介质定义的分布中生成样本。

## 2.3.1 离散情况

[[C2.1-monte-carlo-basics-translation#^eq-2-2|公式 (2.2)]] 给出了使用均匀随机变量从一组离散概率中采样的算法。假设有一个过程有四种可能的结果，概率分别为 $p_1, p_2, p_3, p_4$，其中 $\sum_i p_i = 1$。对应的 PMF 如图 2.3 所示。

^fig-2-3

[[C2.1-monte-carlo-basics-translation#^eq-2-2|公式 (2.2)]] 中的求和与 CDF 的定义之间有直接联系。离散 CDF 为：

$$P_i = \sum_{j=1}^{i} p_j$$

图形上的解释是将 PMF 的各条从左到右叠加在一起。这个想法如图 2.4 所示。

<div style="text-align: center;">

*图 2.4：与图 2.3 中 PMF 对应的离散 CDF。每一列的高度等于它所代表的事件的 PMF 加上前面所有事件的 PMF 之和，即 $P_i = \sum_{j=1}^{i} p_j$。*
^fig-2-4

[[C2.1-monte-carlo-basics-translation#^eq-2-2|公式 (2.2)]] 的采样操作可以表示为找到满足以下条件的 $i$：

$$P_{i-1} \le \xi < P_i \tag{2.19}$$
^eq-2-19

这可以理解为反转 CDF $P$——这就是该技术名称的由来。

继续图形解释，这个采样操作可以看作将各事件的概率投影到纵轴上（它们覆盖 $[0,1]$ 范围），然后使用随机变量 $\xi$ 在其中选择（见图 2.5）。这显然是从正确的分布中抽取的——均匀样本命中任何特定条的概率恰好等于该条的高度。

### SampleDiscrete() 实现

`SampleDiscrete()` 函数实现了这个算法。它接收一组不一定归一化的非负权重和一个均匀随机样本 $u$，返回以正比于其权重的概率选中的权重的索引。它执行的采样操作对应于找到满足以下条件的 $i$：

$$\sum_{j=1}^{i-1} w_j \le \xi \cdot \sum w_i < \sum_{j=1}^{i} w_j \tag{2.20}$$
^eq-2-20

这对应于将[[#^eq-2-19|公式 (2.19)]] 两边乘以 $\sum w_i$。（不要求归一化的 PMF 是为了方便调用代码，在函数实现中也增加不了多少工作。）还提供了两个可选参数，用于返回样本的 PMF 值以及从 $u$ 导出的新均匀随机样本。

此函数适用于只需从权重分布中生成单个样本的情况；如果需要多个样本，应使用 `AliasTable`（附录 A.1），它在 $O(n)$ 预处理后以 $O(1)$ 时间生成样本，而 `SampleDiscrete()` 每次生成样本需要 $O(n)$ 时间。

```cpp
int SampleDiscrete(pstd::span<const Float> weights, Float u,
                   Float *pmf, Float *uRemapped) {
    // 处理空权重的离散采样
    if (weights.empty()) { if (pmf) *pmf = 0; return -1; }

    // 计算权重之和
    Float sumWeights = 0;
    for (Float w : weights) sumWeights += w;

    // 计算缩放后的 u' 样本
    Float up = u * sumWeights;
    if (up == sumWeights) up = NextFloatDown(up);

    // 在权重中找到 u' 对应的偏移量
    int offset = 0;
    Float sum = 0;
    while (sum + weights[offset] <= up)
        sum += weights[offset++];

    // 如有需要，计算 PMF 和重映射的 u 值
    if (pmf) *pmf = weights[offset] / sumWeights;
    if (uRemapped)
        *uRemapped = std::min((up - sum) / weights[offset],
                              OneMinusEpsilon);
    return offset;
}
```

空权重的情况先处理，以便后续代码可以假设至少有一个权重。

离散概率——采样第 $i$ 个元素的概率等于 `weights[i]` 除以所有权重值之和。因此函数接下来计算该总和。

按照[[#^eq-2-20|公式 (2.20)]]，均匀样本 $u$ 乘以权重总和得到值 $u'$，用于从权重中采样。即使提供的 $u$ 值应在 $[0,1)$ 范围内，由于浮点舍入，$u \cdot \text{sumWeights}$ 仍可能等于 `sumWeights`。在这种罕见情况下，`up` 被向下推到下一个更小的浮点值，以便后续代码可以假设 $u' < \text{sumWeights}$。

我们希望在权重数组中找到最后一个偏移 $i$，使得随机样本 $u'$ 大于截至 $i$ 的权重之和。采样通过从数组开头线性搜索来执行，累加权重之和，直到该和将大于 $u'$。

`while` 循环终止后，所提供样本 $u$ 中的随机性仅用于选择了数组的一个元素——一个离散选择。样本在包围它的两个 CDF 值之间的偏移量本身是一个均匀随机值，可以轻松重映射到 $[0,1)$。如有请求，这个值通过 `uRemapped` 返回给调用者。

有人可能会问：何必呢？生成均匀随机变量并不困难，所以提供这个选项的好处似乎微不足道。然而，对于第 8 章中的一些高质量样本生成算法，以这种方式复用样本比生成新的样本更有益——因此提供了这个选项。

## 2.3.2 连续情况

要将此技术推广到连续分布，考虑当离散可能性的数量趋于无穷时会发生什么。图 2.3 的 PMF 变成 PDF，图 2.4 的 CDF 变成其积分。投影过程仍然相同，但它有了一个方便的数学解释——它代表反转 CDF 并在 $\xi$ 处求值。

更精确地说，从 PDF $p(x)$ 中抽取样本 $X_i$ 的步骤为：

**第一步：** 积分 PDF 得到 CDF：$P(x) = \int_0^x p(x') \, dx'$

**第二步：** 获取均匀分布的随机数 $\xi$

**第三步：** 求解 $\xi = P(X)$ 得到 $X$；换言之，找到 $X = P^{-1}(\xi)$

我们将用一个简单的例子来说明这个算法；更多函数的应用参见附录 A.4。

### 采样线性函数

函数 $f(x) = (1-x)a + xb$ 在 $[0,1]$ 上定义，从 $x=0$ 处的 $a$ 线性插值到 $x=1$ 处的 $b$。这里假设 $a, b \ge 0$；本章末尾的练习讨论更一般的情况。

```cpp
Float Lerp(Float x, Float a, Float b) {
    return (1 - x) * a + x * b;
}
```

函数的积分为 $\int_0^1 f(x) \, dx = (a+b)/2$，由此得到归一化常数 $2/(a+b)$ 来定义其 PDF：

$$p(x) = \frac{2 f(x)}{a + b}$$

```cpp
Float LinearPDF(Float x, Float a, Float b) {
    if (x < 0 || x > 1) return 0;
    return 2 * Lerp(x, a, b) / (a + b);
}
```

积分 PDF 得到 CDF，它是一个二次函数：

$$P(x) = \frac{x \left(a(2-x) + bx\right)}{a + b}$$

反转 $\xi = P(X)$ 得到采样公式。数值稳定的形式为：

$$X = \frac{\xi(a+b)}{a + \sqrt{(1-\xi)a^2 + \xi b^2}}$$

```cpp
Float SampleLinear(Float u, Float a, Float b) {
    if (u == 0 && a == 0) return 0;
    Float x = u * (a + b) /
        (a + std::sqrt(Lerp(u, Sqr(a), Sqr(b))));
    return std::min(x, OneMinusEpsilon);
}
```

值得注意的一个细节是 `return` 语句中的 `std::min` 调用，它确保返回值在 $[0,1)$ 范围内。虽然采样算法在 $\xi \in [0,1)$ 时生成该范围内的值，但浮点舍入可能导致结果等于 1。因为调用采样例程的一些代码依赖于返回值在指定范围内，采样例程必须确保这一点。

除了提供从分布中采样和计算样本 PDF 的函数外，pbrt 通常还提供反转采样操作的函数——返回与值 $x$ 对应的随机样本 $\xi$。在一维情况下，这等价于计算 CDF。

```cpp
Float InvertLinearSample(Float x, Float a, Float b) {
    return x * (a * (2 - x) + b * x) / (a + b);
}
```
