# §2.4 分布间变换

在介绍反演法时，我们引入了一种通过以特定方式变换标准均匀随机变量来按某种分布生成样本的技术。这里，我们将研究一个更一般的问题：当我们用函数 $f$ 将样本从任意分布变换到另一个分布时，结果是什么分布？理解这种变换的效果有多种用处，但这里我们将重点关注它如何帮助我们推导多维采样算法。

## 一维变换

假设给定一个随机变量 $X$，它从 PDF $p(x)$ 中抽取，CDF 为 $P(x)$。给定一个函数 $f(x)$，其中 $y = f(x)$，如果我们计算 $Y = f(X)$，我们想求新随机变量 $Y$ 的分布。

在这种情况下，函数 $f(x)$ 必须是一对一变换；如果多个 $x$ 值映射到同一个 $y$ 值，那就无法无歧义地描述特定 $y$ 值的概率密度。$f$ 是一对一的直接推论是其导数必须要么严格大于 0 要么严格小于 0，这意味着对于给定的 $x$：

$$\Pr\{Y \le f(x)\} = \Pr\{X \le x\}$$

从 CDF 的定义（[[C2.1-monte-carlo-basics-translation#^eq-2-3|公式 (2.3)]]）可以看到：

$$P_f(y) = P_f(f(x)) = P(x)$$

这个 CDF 之间的关系直接导出 PDF 之间的关系。如果我们假设 $f$ 的导数大于 0，对两边求导得：

$$p_f(y) \cdot \frac{df}{dx} = p(x)$$

因此：

$$p_f(y) = \left(\frac{df}{dx}\right)^{-1} \cdot p(x)$$

一般情况下，$f$ 的导数要么严格正要么严格负，两种密度之间的关系是：

$$p_f(y) = \left|\frac{df}{dx}\right|^{-1} \cdot p(x)$$

**如何使用这个公式？** 假设 $p(x) = 2x$（定义在 $[0,1]$ 上），令 $f(x) = \sin(x)$。随机变量 $Y = f(X)$ 的 PDF 是什么？因为 $df/dx = \cos(x)$，所以：

$$p_f(y) = \frac{p(x)}{|\cos(x)|} = \frac{2x}{\cos(x)} = \frac{2 \arcsin(y)}{\sqrt{1 - y^2}}$$

这个过程看起来可能是"反着来的"——通常我们有一个想从中采样的 PDF，而不是一个给定的变换。例如，我们可能有从某个 $p(x)$ 抽取的 $X$，想要计算服从某个分布 $p_f(y)$ 的 $Y$。应该使用什么变换？我们只需要让两个 CDF 相等，即 $P_f(y) = P(x)$，这立即给出变换：

$$f(x) = P_f^{-1}(P(x))$$

这是反演法的推广——因为如果 $X$ 在 $[0,1)$ 上均匀分布，则 $P(x) = x$，我们就得到了之前介绍的同一个过程。

## 2.4.1 多维变换

在一般 $d$ 维情况下，类似的推导给出不同密度之间的类似关系。这里不展示推导过程；它遵循与一维情况相同的形式。

假设有一个 $d$ 维随机变量 $X$，密度函数为 $p(x)$。令 $Y = T(X)$，其中 $T$ 是一个双射。此时，密度之间的关系为：

$$p_T(y) = p_T(T(x)) = \frac{p(x)}{|J_T(x)|} \tag{2.21}$$
^eq-2-21

其中 $|J_T|$ 是 $T$ 的 Jacobian 矩阵行列式的绝对值：

$$J_T = \begin{vmatrix} \frac{\partial T_1}{\partial x_1} & \cdots & \frac{\partial T_1}{\partial x_d} \\ \vdots & \ddots & \vdots \\ \frac{\partial T_d}{\partial x_1} & \cdots & \frac{\partial T_d}{\partial x_d} \end{vmatrix}$$

其中下标索引 $T(x)$ 和 $x$ 的各个维度。

### 极坐标变换的例子

极坐标变换将笛卡尔坐标 $(x, y)$ 与极坐标 $(r, \theta)$ 关联：

$$x = r \cos\theta, \quad y = r \sin\theta$$

假设我们从某个密度 $p(r, \theta)$ 中采样，对应的密度 $p(x, y)$ 是什么？此变换的 Jacobian 为：

$$J_T = \begin{vmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta \end{vmatrix} = r(\cos^2\theta + \sin^2\theta) = r$$

所以 $p(x, y) = p(r, \theta) / r$。当然，通常我们是反过来的——从笛卡尔坐标的采样策略出发，想变换到极坐标。那种情况下：

$$p(r, \theta) = r \cdot p(x, y) \tag{2.22}$$
^eq-2-22

在三维中，给定方向的球坐标表示（公式 3.7），该变换的 Jacobian 行列式为 $|J_T| = r^2 \sin\theta$，所以对应的密度函数为：

$$p(r, \theta, \varphi) = r^2 \sin\theta \cdot p(x, y, z) \tag{2.23}$$
^eq-2-23

这个变换很重要，因为它帮助我们将方向表示为单位球面上的点 $(x, y, z)$。

## 2.4.2 多维变换采样

假设有一个二维联合密度函数 $p(x, y)$，我们想从中抽取样本 $(X, Y)$。如果密度是独立的，它们可以表示为一维密度的乘积：

$$p(x, y) = p_x(x) \cdot p_y(y)$$

随机变量 $(X, Y)$ 可以通过独立地从 $p_x$ 采样 $X$ 和从 $p_y$ 采样 $Y$ 来获得。然而，许多有用的密度不可分离，因此我们引入一般情况下从多维分布采样的理论。

### Marginal-Conditional 方法

给定二维密度函数，边缘密度函数 $p(x)$ 通过"积分掉"一个维度得到：

$$p(x) = \int p(x, y) \, dy \tag{2.24}$$
^eq-2-24

这可以理解为 $X$ 单独的密度函数。更精确地说，它是特定 $x$ 值在所有可能的 $y$ 值上的平均密度。

如果我们能抽取样本 $X \sim p(x)$，那么——利用[[C2.1-monte-carlo-basics-translation#^eq-2-1|公式 (2.1)]]——为了采样 $Y$，我们需要从条件概率密度 $Y \sim p(y|x)$ 中采样，它由以下公式给出：

$$p(y|x) = \frac{p(x, y)}{\int p(x, y) \, dy}$$

从更高维分布的采样可以类似地进行：积分掉除一个维度之外的所有维度，采样该维度，然后对剩余的条件分布（少了一个维度）应用相同技术。

### 采样双线性函数

双线性函数：

$$f(x, y) = (1-x)(1-y)w_0 + x(1-y)w_1 + y(1-x)w_2 + x \cdot y \cdot w_3 \tag{2.25}$$
^eq-2-25

在 $[0,1]^2$ 的四个角之间插值。（$w_0$ 在 $(0,0)$，$w_1$ 在 $(1,0)$，$w_2$ 在 $(0,1)$，$w_3$ 在 $(1,1)$。）

积分和归一化后，其 PDF 为：

$$p(x, y) = \frac{4 \, f(x, y)}{w_0 + w_1 + w_2 + w_3}$$

```cpp
Float BilinearPDF(Point2f p, pstd::span<const Float> w) {
    if (p.x < 0 || p.x > 1 || p.y < 0 || p.y > 1)
        return 0;
    if (w[0] + w[1] + w[2] + w[3] == 0)
        return 1;
    return 4 *
        ((1-p[0]) * (1-p[1]) * w[0] + p[0] * (1-p[1]) * w[1] +
         (1-p[0]) * p[1] * w[2] + p[0] * p[1] * w[3]) /
        (w[0] + w[1] + w[2] + w[3]);
}
```

此函数的两个维度不独立，所以采样方法先采样边缘分布，再采样条件分布。

**第一步：采样 $y$ 的边缘分布。** 我们可以选择 $x$ 或 $y$ 作为边缘分布。如果选择 $y$ 并积分掉 $x$：

$$p(y) = \int_0^1 p(x, y) \, dx = \frac{2 \left((1-y)(w_0+w_1) + y(w_2+w_3)\right)}{w_0+w_1+w_2+w_3} \propto (1-y)(w_0+w_1) + y(w_2+w_3)$$

$p(y)$ 在两个常数值之间线性插值，所以可以用 `SampleLinear()` 来采样：

```cpp
p.y = SampleLinear(u[1], w[0] + w[1], w[2] + w[3]);
```

**第二步：采样 $x$ 的条件分布。** 应用[[C2.1-monte-carlo-basics-translation#^eq-2-1|公式 (2.1)]] 并化简公共因子：

$$p(x|y) = \frac{p(x,y)}{p(y)} \propto (1-x) \cdot \left[(1-y)w_0 + y \cdot w_2\right] + x \cdot \left[(1-y)w_1 + y \cdot w_3\right]$$

这也可以用 `SampleLinear()` 采样：

```cpp
p.x = SampleLinear(u[0], Lerp(p.y, w[0], w[2]), Lerp(p.y, w[1], w[3]));
```

**完整的采样函数：**

```cpp
Point2f SampleBilinear(Point2f u, pstd::span<const Float> w) {
    Point2f p;
    p.y = SampleLinear(u[1], w[0] + w[1], w[2] + w[3]);
    p.x = SampleLinear(u[0],
        Lerp(p.y, w[0], w[2]),
        Lerp(p.y, w[1], w[3]));
    return p;
}
```

因为双线性采样例程基于两个一维线性采样操作的组合，所以可以通过以相反顺序应用这两个操作的逆来反转它：

```cpp
Point2f InvertBilinearSample(Point2f p, pstd::span<const Float> w) {
    return {
        InvertLinearSample(p.x,
            Lerp(p.y, w[0], w[2]),
            Lerp(p.y, w[1], w[3])),
        InvertLinearSample(p.y, w[0] + w[1], w[2] + w[3])
    };
}
```
